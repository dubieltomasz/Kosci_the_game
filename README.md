# Kosci_the_game
Dice game based on the rules of Yahtzee 

## Requirements
- Windows x64
- C# .NET 8

## Rules
- Up to 4 players
- Every Player has up to 3 rolls per round
- [All rules](https://en.wikipedia.org/wiki/Yahtzee)

## Instalation
You can download the .exe [here](https://github.com/dubieltomasz/Kosci_the_game/releases/latest), or clone the repository and compile using at least Visual Studio 2022 with C# .NET 8.
